01เริ่มใช้งานใน 5 นาที

ระบบนี้รวมงานแจ้งปัญหา ตารางงานการผลิต และข้อมูลคลังสินค้า (Item stock, Pending Order, ใบสั่ง, การจอง BOM) ไว้ในเว็บเดียว เปิดได้จากเบราว์เซอร์ทั้งคอมพิวเตอร์และมือถือ ไม่ต้องติดตั้งโปรแกรม

  1. เปิดลิงก์เว็บแอปที่ได้รับจาก Admin (บันทึกเป็น Bookmark ไว้ใช้ครั้งต่อไป)
  2. ดูเมนูด้านซ้าย (บนมือถือกดปุ่มเมนูมุมบน) เลือกงานที่ต้องการ เช่น แจ้งปัญหาใหม่ หรือ Item stock
  3. ต้องการค้นหาอะไรด่วน ใช้ช่อง ค้นหา ด้านบน หรือกด Ctrl+K (Mac: ⌘+K)
  4. ขณะระบบโหลดหรือบันทึก จะมีแถบแสดงสถานะ "กำลังโหลด… / กำลังบันทึก…" รอจนหายไปก่อนกดซ้ำ
  5. ถ้าเป็นผู้ดูแล กด ปลดล็อค ที่กล่อง Admin: Locked มุมล่างซ้าย แล้วใส่รหัส Admin
เคล็ดลับข้อมูลที่เปิดบ่อย (รายการเคส, Item stock) ถูกเก็บสำรองไว้ในเครื่อง หน้าจอจึงแสดงผลได้ทันทีแล้วค่อยอัปเดตเป็นข้อมูลล่าสุดตามมา

ปลดล็อคและล็อค Admin

  1. กด ปลดล็อค ที่กล่อง Admin: Locked มุมล่างซ้าย
  2. ใส่รหัส Admin แล้วกดยืนยัน ป้ายมุมบนจะเปลี่ยนจาก USER เป็น Admin และมีเมนูดูแลระบบเพิ่มขึ้น
  3. ใช้เสร็จ กดล็อคกลับ หรือปุ่ม User Mode ด้านบนเพื่อดูหน้าจอแบบผู้ใช้ทั่วไป
ความปลอดภัยรหัส Admin ตั้งที่ Apps Script → Project Settings → Script properties ชื่อ ADMIN_PASSCODE ถ้ายังไม่ได้ตั้ง ระบบจะใช้รหัสเริ่มต้น ควรตั้งรหัสใหม่ทันที สิทธิ์ Admin หมดอายุเองเมื่อไม่ได้ใช้นาน ถ้าขึ้นข้อความ "สิทธิ์ Admin หมดอายุ" ให้ปลดล็อคใหม่

03ส่วนประกอบหน้าจอ

งานของฉัน (หน้าแรก)

เลือกบทบาทด้านขวาบน: จัดซื้อ · คลังสินค้า · ผู้อนุมัติ · Admin ระบบจำไว้ จัดซื้อเห็นสิ่งที่ต้องสั่งวันนี้พร้อมปุ่มสร้างใบสั่ง (ใส่ชื่อ DES'D เพื่อดูใบสั่งของตัวเอง) คลังเห็นคิวใบเบิกและของเข้า 7 วัน

แผงข้อมูล CODE

คลิก CODE ที่ไหนก็ได้ จะเปิดแผงด้านขวา: Onhand แยกคลัง/PK, กำลังเข้า, จอง BOM, ใบสั่ง/PO, Stock Alert, Stock ช่วยใช้, กราฟคงเหลือและคาดวันหมด กด Esc หรือ ✕ เพื่อปิด

โปรเจกต์ (Project 360)

หน้าเดียวต่อโปรเจกต์: % ความพร้อมผลิต, ไทม์ไลน์ (Import BOM, ใบสั่ง, Export ใบเบิก, LCC/RCC Start, Delivery), สิ่งที่ยังไม่พร้อมพร้อมความคืบหน้า และเคสที่เกี่ยวข้อง · การ์ด ใบสั่งของโปรเจกต์ รวมทั้ง Order Item และ Order Project จาก Pending Order (ดูกล่องด้านล่าง)

เมนูด้านซ้าย

รายการงานทั้งหมด จุดสีข้างเมนูแปลว่ามีเรื่องรอดู เมนูที่ Admin ซ่อนไว้จะไม่แสดงในโหมดผู้ใช้

แถบบน

ชื่อหน้า สถานะการเชื่อมต่อ Google Sheets ช่องค้นหา (Ctrl+K) กระดิ่งแจ้งเตือน ปุ่ม User Mode และปุ่ม + แจ้งปัญหา

กระดิ่งแจ้งเตือน

แจ้งเมื่อเคสมีการตอบกลับ เปลี่ยนสถานะ หรือมีใบสั่งรออนุมัติ

ปุ่มมุมขวาล่างทุกหน้า: แจ้งปัญหาการใช้งาน เสนอไอเดีย หรือชม ไม่ต้องล็อกอิน ใส่ชื่อหรือไม่ก็ได้

ปุ่มเส้นแนวนอนบนแถบบน (คอมพิวเตอร์): แน่น = เห็นได้หลายแถวในจอเดียว · โปร่ง = อ่านง่าย ระบบจำไว้ในเครื่อง · บนมือถือ ตารางจะแสดงเป็นการ์ดอัตโนมัติ ไม่ต้องเลื่อนซ้ายขวา

04แดชบอร์ด ทุกคน

ภาพรวมเคสแจ้งปัญหา แผนงาน 14 วันข้างหน้า และ (สำหรับ Admin) สรุป Stock Alert

  • บอร์ดเคส แบ่งตามสถานะ กดการ์ดเพื่อเปิดรายละเอียดและแชทของเคส
  • แผน 14 วัน แสดง 5 รายการแรก กด "ดูทั้งหมด" เพื่อขยาย
  • Stock Alert แสดงเฉพาะ Admin กดเพื่อไปหน้า Stock Alert

สถานะของเคส

New→In Progress→Waiting→Resolved→Closed

Waiting = รอข้อมูลหรือรออะไหล่ · Resolved = แก้แล้ว รอยืนยัน · Closed = ปิดเคส

05แจ้งปัญหาใหม่ ทุกคน

  1. กด + แจ้งปัญหา มุมบนขวา หรือเมนู แจ้งปัญหาใหม่
  2. ถ้ามีปุ่มแม่แบบ เลือกแม่แบบที่ตรงกับปัญหา ระบบเติมหัวข้อ รายละเอียด หมวด และความสำคัญให้
  3. กรอก Project / งานที่เกี่ยวข้อง รายละเอียดปัญหา ชื่อผู้แจ้ง แผนก และอีเมล (ใส่อีเมลเพื่อรับแจ้งเมื่อมีความคืบหน้า)
  4. เลือกหมวด: อุปกรณ์ไม่มีติดตั้ง · ปรับปรุง · แก้ไขวายริ่ง · NC · เครื่องมือชำรุด · ระบบไอที · อื่นๆ และเลือกความสำคัญ
  5. แนบรูปหรือไฟล์ (รูปภาพ, PDF, Office) แล้วกด ส่ง จะได้เลขเคสไว้ติดตาม

ติดตามและคุยในเคส

เปิดเคสจากแดชบอร์ด พิมพ์ข้อความในช่องแชทเพื่อสอบถามหรือส่งข้อมูลเพิ่ม ผู้ใช้ทั่วไปเพิ่มข้อความได้อย่างเดียว การเปลี่ยนสถานะและผู้รับผิดชอบทำโดย Admin

10.1ติดตามใบสั่ง และแจ้งเตือนของเข้า

เมนู ติดตามใบสั่ง (กลุ่มคลังและจัดซื้อ) แสดงทุกใบสั่งเป็นขั้นตอนต่อเนื่อง ไม่ต้องโทรถามว่าของถึงไหน · ตัวเลขข้างเมนู = ใบสั่งที่ยังไม่ถึง "ของเข้าครบ" (สีแดง = มีใบที่ต้องตาม · น้ำเงิน = กำลังดำเนินการตามปกติ) ชี้ที่ตัวเลขเพื่อดูแยกตามขั้นตอน

บันทึก→ส่งขออนุมัติ→อนุมัติ→พบใน Pending (PR)→ออก PO→ของเข้าครบ
  1. ระบบจับคู่ใบสั่งกับ Pending Order ด้วย เลข RQN หรือ Spec No ที่เขียนในใบสั่ง (ต้องตรงกับ Requisition_No / Specification_No) แล้วดูสถานะราย CODE · ถ้าเลขในใบสั่งยังไม่ครบ (เช่น RQN26- / DS1C26-) ระบบจะ 🔗 จับคู่อัตโนมัติจาก CODE + วันที่ขอซื้อ (PR ของ CODE เดียวกันที่ขอซื้อ 3 วันก่อน ถึง 90 วันหลังวันออกใบสั่ง และยังไม่ถูกใบอื่นจับคู่ จำนวนเท่ากันได้ก่อน) พร้อมกรอบสีฟ้าบอกเลข PR ที่จับได้
  2. 🔢 เติมเลขกลับลงใบสั่งอัตโนมัติ: ถ้าจับคู่ได้ชัดเจน (ทุก CODE ได้ PR เดียวกันของปีเดียวกับใบสั่ง และจำนวนตรงกัน) ระบบเติมเลข RQN (และ Spec ถ้าเป็นเลข 3 หลักตามแบบฟอร์ม) ลงใบสั่งให้เองในรอบซิงค์ถัดไป พร้อมแจ้งเตือน 📦 และบันทึกใน Audit log · ถ้ายังไม่ชัดเจน (เช่น จำนวนไม่ตรง) จะมีปุ่ม ✓ ใช้เลขนี้ในใบสั่ง ให้กดยืนยันเอง · ระบบเติมเฉพาะช่องที่ยังว่าง ไม่ทับเลขที่กรอกไว้แล้ว
  3. ตัวกรองด้านบน: ยังไม่ครบ · ⚠ ต้องตาม · รออนุมัติ · รอเข้าระบบจัดซื้อ · มี PR · ออก PO · เข้าบางส่วน · ครบแล้ว ติ๊ก เฉพาะของฉัน แล้วใส่ชื่อ DES'D เพื่อดูเฉพาะใบสั่งของตัวเอง
  4. "⚠ ต้องตาม" คือ PO เลยกำหนดส่ง · อนุมัติแล้วเกิน 7 วันแต่ยังไม่พบใน Pending Order · ค้างอนุมัติเกินกำหนด

ฝ่ายผลิต: แจ้งปัญหาหน้างาน
  1. + แจ้งปัญหา → เลือกแม่แบบ → แนบรูป → ส่ง
  2. จดเลขเคส ติดตามที่แดชบอร์ด ตอบแชทเมื่อมีคำถาม
  3. เมื่อสถานะเป็น Resolved ตรวจหน้างาน ถ้ายังไม่เรียบร้อยให้พิมพ์แจ้งในแชท
จัดซื้อ / DS13: เช้าวันทำงาน
  1. เปิด Stock Alert ดูระดับ "สูงสุด" และ "กลาง" ก่อน
  2. ติ๊กเลือก → สร้างใบสั่ง → อ่านป๊อปอัปสั่งซ้ำ
  3. ตรวจ Stock ช่วยใช้ว่ามีของใช้แทนได้หรือไม่
  4. บันทึก → ส่งออก PDF → ส่งขออนุมัติ
  5. ติดตามที่แท็บ รอการอนุมัติ
วางแผน: รับโปรเจกต์ใหม่เข้าผลิต
  1. ตรวจตารางงานว่ามี ProjectNo และ Start-date ของ LCC/RCC
  2. Admin Import BOM ของโปรเจกต์ (D01, D02, …)
  3. ดูการ์ดโปรเจกต์: ❌ ขาด / ⚠ เข้าไม่ทัน
  4. กด 📄 PDF รายการที่ขาด ส่งให้ทีมที่เกี่ยวข้อง
  5. กด 🛒 สร้างใบสั่งจากรายการที่ขาด ทำใบสั่ง ทีละ 8 รายการ
คลังสินค้า: เบิกของเข้าไลน์ผลิต
  1. Booking BOM → เปิดโปรเจกต์ → 📤 Export ใบเบิก By Stock
  2. ตรวจจำนวนและคลัง แก้/ลบ/เพิ่มใน Preview
  3. Export → พิมพ์ → ติด Barcode ในช่อง G และ I → เซ็นชื่อ
  4. ของเฉพาะงาน (16 หลัก) ใช้ By Project แบบเดียวกัน
  5. Admin ปิดโปรเจกต์หลังเบิกครบ เพื่อปลดยอดจอง
Admin: ตรวจระบบรายสัปดาห์
  1. ตั้งค่าระบบ: เวลาซิงค์ล่าสุดของทุกแหล่งข้อมูลเป็นปัจจุบัน
  2. สุขภาพระบบ: สำรองข้อมูล และดู Audit log
  3. Booking BOM: ปิดโปรเจกต์ที่ผลิตเสร็จ
